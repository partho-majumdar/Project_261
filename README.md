## 📖 About The Project

**Project 261** is a full-stack Project Management System developed using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**. The system helps teams efficiently manage projects, assign tasks, monitor progress, and improve collaboration through a centralized platform.

The application aims to simplify project execution by providing project tracking, task assignment, deadline management, and real-time project status monitoring.

---

## ✨ Key Features

### 👤 User Management(Student)
- User Registration & Login
- Secure Authentication
- Role-Based Access Control
- User Profile Management
- File Submission
- Career guideline from AI

### 📂 Project Management(Supervisor)
- Create New Projects
- Update Project Details
- Project Categorization
- Project Progress Tracking
- Project Status Monitoring
- Presentation date fixation

### 📊 Dashboard & Analytics
- Overview Dashboard
- Project Statistics
- Task Completion Tracking
- Performance Monitoring

### 🔔 Notifications

- Deadline Reminders
